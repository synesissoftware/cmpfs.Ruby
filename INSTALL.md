## Install the gem

```
gem install cmpfs-ruby
```

or add to a **Gemfile**:

```Ruby
gem 'cmpfs-ruby'
```

then `bundle install`.


## From a source checkout

```
bundle install
bundle exec rake test
```


## Using the library

```Ruby
require 'cmpfs'
```
